# Welcome to My Blog

This is my first blog post using Next.js and MDX. I'm excited to share my thoughts and experiences with you.

## Why Next.js and MDX?

Next.js provides an excellent framework for building static and server-rendered React applications. Combined with MDX, it offers a powerful way to write content using Markdown with React components.

### Features I Love

1. **Markdown Syntax** - Simple and intuitive way to write content
2. **React Components** - Ability to use React components within markdown
3. **Static Generation** - Fast loading times and great SEO
4. **Dark Mode Support** - Built-in dark mode for better reading experience

  return `Hello, ${name}!`;
}
